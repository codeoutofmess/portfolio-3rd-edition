<Step n="01" title="Why a port">
A to do app proves very little. So I took the event list, event detail and filter form from [Paste Up](/case/paste-up) and rebuilt just those in Angular, against the same data. The README says it's deliberate.
</Step>

<Media src="/images/work/paste-up/architecture.svg" caption="ConsoleView calls a small API added to Paste Up, rather than reaching into its database." />

<Step n="02" title="The API didn't exist">
Paste Up talked to its database straight from the server, so there was nothing for Angular to call. I added two read only endpoints and shaped the data on the server, so the Angular side stayed simple.
</Step>

<Step n="03" title="Signals all the way">
The filter form becomes a signal and the list is worked out from it, so neither page has to manage subscriptions by hand. Angular 22 also renamed one of its core decorators, which I found out from a failed build.
</Step>

<Step n="04" title="Where it stands">
It works end to end against Paste Up's real data, but only on my machine for now. It isn't deployed yet.
</Step>
