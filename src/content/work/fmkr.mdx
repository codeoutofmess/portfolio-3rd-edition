<Step n="01" title="The problem">
Most label sites are a roster and a list of releases. FMKR wanted to read as a company that owns catalogue and builds brands, without turning into a corporate brochure.
</Step>

  <Media src="/images/work/fmkr/cover.webp" caption="One hand drawn object, the links in the corner." />
  <Media src="/images/work/fmkr/phone.jpg" caption="The same page on a phone." />
</Pair>

<Step n="02" title="Built around who visits">
Artists, partners and people asking about rights each arrive with a different question, so the navigation answers those questions. Enquiries go to separate desks, so a demo reaches A&R and a licensing request reaches rights.
</Step>

<Media src="/images/work/fmkr/statement.jpg" caption="The statement band." />

<Step n="03" title="The redesign">
My first passes looked like every other site: an orb, a gradient, a floating 3D thing. So I set a few rules. One hero object, a few huge elements and the rest small, and no header bar. The object became a knife animation I drew by hand.
</Step>
